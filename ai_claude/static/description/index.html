Quick Setup

1. Install Module: Install through Odoo's Apps menu. Requires Enterprise AI module (ai) and AI App module (ai_app).

2. Get API Key: Sign up at console.anthropic.com and generate your Claude API key.

3. Configure: Go to Settings → AI or AI App Settings → Claude Integration. Enter your API key and save.

4. Select Model: When creating an AI Agent, select your preferred Claude model from the LLM Model dropdown.

5. Test: Create a test AI agent and verify it responds correctly.

Requirements


Odoo Version: Odoo 19.0 or later (Enterprise Edition)


API Access: Claude API key from Anthropic
